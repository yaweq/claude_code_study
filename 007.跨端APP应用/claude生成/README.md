# 每日记账 · 跨端 APP（007.跨端APP应用）

基于 **uni-app**（Vue 语法）开发的个人财务记账应用，一套代码同时编译到 **安卓 / iOS / 微信小程序 / H5**，功能与 PRD 及 Web 端（004.frontend + 006.后端代码）一致。

## 目录结构

```
007.跨端APP应用/
├── App.vue            # 应用入口 + 全局样式
├── main.js            # 入口
├── manifest.json      # 应用配置（appid、各端配置）
├── pages.json         # 页面路由 + 底部 tabBar
├── utils/
│   ├── api.js         # 后端 REST API 封装
│   └── format.js      # 金额/日期格式化工具
├── pages/
│   ├── index/         # 首页（本月收支 + 快捷记账 + 今日/昨日明细）
│   ├── bills/         # 账单（四类筛选 + 一键清除 + 长按删除）
│   ├── record/        # 记账（金额/分类/账户/日期/备注，写库）
│   ├── stats/         # 统计（收支概览 + 分类构成 + 近6月趋势）
│   └── profile/       # 我的（分类/预算/导出/回收站入口）
└── static/            # 静态资源（可放 tabBar 图标等）
```

## 运行方式

用 **HBuilderX**（推荐）打开本目录，选择「运行到浏览器 / 手机 / 微信开发者工具」即可。

- **H5 / 浏览器**：直接运行，访问后端 `http://127.0.0.1:3000`。
- **安卓 / iOS**：需真机或模拟器，并把后端地址改成电脑局域网 IP（见下）。
- **微信小程序**：需在 HBuilderX 里配置 `manifest.json` 的 `mp-weixin.appid` 为你的小程序 AppID，并用微信开发者工具打开。

## ⚠️ 后端地址配置（重要）

`utils/api.js` 顶部的 `BASE_URL` 默认为：

```js
const BASE_URL = 'http://127.0.0.1:3000'
```

- **H5/浏览器**：`127.0.0.1` 可用。
- **安卓/iOS 真机**：`127.0.0.1` 指向手机自身，需改成后端电脑的局域网 IP，例如 `http://192.168.1.100:3000`。
- **微信小程序**：要求后端为 **HTTPS** 且域名已在小程序后台配置为合法 request 域名（本地 HTTP 无法直接联调，需用开发者工具勾选「不校验合法域名」）。

## 依赖后端

本应用需要后端 `006.后端代码` 运行（`cd 006.后端代码 && npm start`），数据来自 MySQL 的 `finance` 库。

## 功能对照

| 页面 | 功能 |
| --- | --- |
| 首页 | 本月收支卡片、快捷记账、今日/昨日明细、空态、悬浮记账按钮 |
| 账单 | 类型/分类/账户/日期四类筛选、一键清除、长按删除（软删除） |
| 记账 | 支出/收入切换、金额输入、分类宫格、账户/日期/备注、POST 写库 |
| 统计 | 收支概览、分类构成条形图、近 6 月收支趋势柱状图 |
| 我的 | 分类管理/预算/导出/回收站入口（部分为占位，待后续实现） |

## 说明

- 金额统一以「元」DECIMAL 存储，与后端一致，页面与数据库显示同值。
- 底部导航为 4 个 tab（首页/账单/统计/我的），「记账」入口在首页悬浮按钮和快捷记账。
- tabBar 暂为文字样式，可自行在 `static/` 放入图标并在 `pages.json` 配置 `iconPath`。
