## 1. 产品概述

### 1.1 背景与问题

用户每天都有各类消费支出（餐饮、交通、购物、娱乐等），但目前记录分散、缺乏系统性。常见痛点：

1. **记账门槛高**：传统记账软件功能复杂，录入一次消费要填写多字段，用户难以坚持。
2. **数据不清晰**：消费记录散落在微信、支付宝账单里，难以形成统一的支出视图。
3. **缺乏洞察**：用户知道"钱花出去了"，但不清楚"花在了哪里、是否超支、趋势如何"。
4. **缺乏约束**：没有预算预警，月底才发现超支，无法主动控制。

### 1.2 产品定位

一款**面向个人用户的轻量级日常记账工具**，核心是「**极速记账 + 清晰洞察 + 预算约束**」。让用户用最低的操作成本记录每一笔消费，并用直观的图表帮用户看懂自己的钱去了哪里。

### 1.3 目标用户

| 画像 | 特征 | 核心诉求 |
| --- | --- | --- |
| 职场新人 / 学生 | 收入有限，对开销敏感 | 搞清楚钱花哪了，控制月开销 |
| 月光族 | 记了几天就放弃 | 极低门槛，随手记，坚持得下去 |
| 家庭主理人 | 管理家庭日常开销 | 多分类统计、月度汇总 |

### 1.4 产品价值

- **对用户**：3 秒完成一笔记账；随时看清收支全貌；预算超标及时提醒，养成理财习惯。
- **对产品**：高频（每天打开）→ 高留存 → 数据积累形成护城河，后续可延展理财、账本共享等增值能力。

## 4. 功能需求详述

### 4.1 记账（核心功能，P0）

#### 4.1.1 功能描述
用户录入一笔收支记录，是产品最高频的核心操作。

#### 4.1.2 录入字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 金额 | 必填 | 数字键盘输入，支持两位小数；支出默认正数 |
| 类型 | 必填 | 支出 / 收入，默认「支出」 |
| 分类 | 必填 | 从分类列表选择，带图标；记住上次选择 |
| 日期 | 选填 | 默认今天，可改（用于补录） |
| 备注 | 选填 | 自由文本，≤100 字 |
| 账户 | 选填 | 现金 / 微信 / 支付宝 / 银行卡（默认现金，可记住） |

#### 4.1.3 交互要求

- **极速记账**：打开即进入金额输入态，数字键盘自动弹出；金额 + 分类两步即可完成（其余字段有默认值）。
- 输入金额后直接展示分类宫格，一键选中即保存，全程 ≤3 秒。
- 保存后给予轻量反馈（toast「已记录 ¥28.00」），不打断后续连续记账。
- 支持「再记一笔」连续录入，保持当前分类/类型不变。

#### 4.1.4 边界与校验

- 金额范围：0.01 ~ 999,999,999.99；超范围或非法输入禁止保存并提示。
- 金额为 0 或负数（支出）时禁止保存。
- 收入金额同样校验。

#### 4.1.5 验收标准（AC）

- [ ] 打开 App 进入记账页，键盘自动弹出，焦点在金额框。
- [ ] 输入「28」→ 点「餐饮」分类 → 记录成功，返回首页并出现该笔记录。
- [ ] 修改日期可成功补录到历史日期。
- [ ] 金额非法（如空、0、负）时无法保存并给出提示。

---

### 4.2 分类管理（P0）

#### 4.2.1 功能描述
支出与收入各有一套分类，带图标与颜色，支持自定义。

#### 4.2.2 默认分类

**支出**：🍜 餐饮、🚇 交通、🛒 购物、🏠 住房、💡 水电煤、📱 通讯、🎮 娱乐、💊 医疗、🎓 教育、🐶 宠物、✈️ 旅行、📦 其他

**收入**：💰 工资、🎁 奖金、📈 理财收益、🧧 红包、📦 其他

#### 4.2.3 交互要求

- 分类以宫格展示，长按可排序，进入「管理分类」可新增 / 重命名 / 删除 / 更换图标。
- 删除分类时，若该分类下已有账目，需提示并允许「迁移到其他分类」。
- 分类顺序影响记账页展示顺序，常用分类置顶。

#### 4.2.4 验收标准

- [ ] 新增分类「健身」后，记账页可选。
- [ ] 删除含账目的分类时，出现迁移提示。
- [ ] 排序结果在记账页生效。

---

### 4.3 账目列表与明细（P0）

#### 4.3.1 功能描述
按时间倒序展示所有账目，支持按日期/分类/类型筛选与搜索。

#### 4.3.2 功能点

| 功能 | 说明 |
| --- | --- |
| 时间分组 | 按「今天 / 昨天 / 本周 / 本月 / 更早」分组，或按日历日分组 |
| 列表项 | 显示分类图标 + 分类名 + 备注 + 金额（支出红色、收入绿色） |
| 筛选 | 类型（全部/支出/收入）、分类、日期区间 |
| 搜索 | 按备注关键词搜索 |
| 编辑/删除 | 点击某条进入编辑；左滑或长按删除，需二次确认 |
| 合计 | 列表顶部/底部显示当前筛选结果合计 |

#### 4.3.3 验收标准

- [ ] 账目按时间倒序展示，金额颜色正确。
- [ ] 按分类筛选只显示该分类账目，合计同步更新。
- [ ] 删除有二次确认，删除后数据不可恢复（或进入回收站，见 4.6）。

---

### 4.4 统计分析（P0）

#### 4.4.1 功能描述
用图表帮助用户理解收支构成与趋势。

#### 4.4.2 报表类型

| 报表 | 内容 |
| --- | --- |
| 收支概览 | 本月总收入 / 总支出 / 结余（大数字卡片） |
| 分类占比 | 环形图，展示各类支出占比，点击可下钻到明细 |
| 月度趋势 | 近 6/12 个月收入 vs 支出柱状图/折线图 |
| 日支出热力 | 日历热力图，颜色深浅表示当日支出高低 |

#### 4.4.3 交互要求

- 支持切换时间维度：周 / 月 / 年。
- 点击环形图某分类，进入该分类的账目明细列表。
- 数据为空时展示引导占位（"本月还没有记录，去记一笔吧"）。

#### 4.4.4 验收标准

- [ ] 录入几笔账后，分类占比与合计数值正确。
- [ ] 点击某分类占比可跳转至筛选后的明细。
- [ ] 空数据时展示占位提示。

---

### 4.5 预算管理与预警（P1）

#### 4.5.1 功能描述
用户可为「总支出」或「某分类」设置月度预算，接近或超出时提醒。

#### 4.5.2 功能点

| 功能 | 说明 |
| --- | --- |
| 设置预算 | 支持总预算 + 分类预算；金额可编辑 |
| 进度展示 | 首页/统计页显示「已用 X / 预算 Y」进度条，百分比 |
| 预警规则 | 达到 80% 提醒「接近预算」，达到 100% 提醒「已超支」 |
| 通知方式 | App 内通知 / 可选系统推送 |

#### 4.5.3 验收标准

- [ ] 设置餐饮预算 1000，当月餐饮支出达 800 时出现预警提示。
- [ ] 超出预算后继续记账，进度条与文案正确提示超支金额。

---

### 4.6 数据管理（P1）

#### 4.6.1 功能描述
保障用户数据安全与可迁移。

| 功能 | 说明 |
| --- | --- |
| 数据导出 | 导出为 CSV / Excel，可分享或保存 |
| 回收站 | 删除的账目进入回收站，30 天后自动清除，可手动恢复 |
| 数据备份 | 本地数据支持导出/导入备份文件（后续可上云） |

#### 4.6.2 验收标准

- [ ] 导出 CSV 可被 Excel 正常打开，字段完整。
- [ ] 删除账目后可在回收站恢复。

## 6. 视觉设计规范（配色方案）

### 6.1 设计基调

整体风格**粉嫩、柔和、治愈**，面向日常消费场景，弱化工具感，营造轻松温暖的记账体验。关键词：**马卡龙色系 · 大圆角 · 圆润字体 · 可爱图标**。

### 6.2 品牌色板（主色）

| 色阶 | 色值 | 用途 |
| --- | --- | --- |
| 主粉 Primary | `#FF7BA9` | 主按钮、底部导航选中态、品牌标识 |
| 深粉 Dark | `#F75C8A` | 主按钮按压态、强调文字 |
| 浅粉 Light | `#FFD6E5` | 选中背景、标签底色、进度条底 |
| 极浅粉 Faint | `#FFECF1` | 浅色块、hover 态、占位块 |

### 6.3 辅助色（马卡龙色系，用于分类图标与图表）

| 颜色 | 色值 | 示例分类 |
| --- | --- | --- |
| 蜜桃粉 | `#FFB3C1` | 购物 |
| 奶油黄 | `#FFD98E` | 娱乐 |
| 薄荷绿 | `#8FE0C3` | 餐饮 |
| 香芋紫 | `#C9B4E8` | 教育 |
| 天空蓝 | `#9FD3E8` | 交通 |
| 珊瑚橙 | `#FFA891` | 旅行 |

### 6.4 功能色（语义色）

> ⚠️ 记账产品通用语义：支出 = 暖红/粉，收入 = 绿。即便整体粉嫩，也必须保留该语义，避免用户混淆收支。

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 支出 | `#FF6B8A` | 支出金额、支出图标 |
| 收入 | `#5EC99A` | 收入金额、收入图标 |
| 预警（接近预算 80%） | `#FFB347` | 预算进度提示 |
| 超支（超出预算 100%+） | `#FF5C7A` | 预算警示 |

### 6.5 中性色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 主文字 | `#4A3F44` | 标题、金额 |
| 次文字 | `#9B8A92` | 说明、时间、占位 |
| 禁用/占位 | `#C9BCC4` | 禁用态、空态 |
| 分割线 | `#F2E6EC` | 列表分割线、边框 |

### 6.6 背景与卡片

| 名称 | 色值 |
| --- | --- |
| 页面背景 | `#FFF7F9`（奶白偏粉） |
| 卡片 / 弹层背景 | `#FFFFFF` |
| 大数字卡片（渐变） | `#FF8FB0 → #FF7BA9` |

### 6.7 应用规范

- **按钮**：主按钮用主粉，圆角 12px；次按钮用浅粉底 + 深粉文字。
- **底部导航**：未选中 `#9B8A92`，选中 `#FF7BA9`。
- **金额**：支出 `#FF6B8A`，收入 `#5EC99A`，加粗显示。
- **图表**：环形图按分类使用马卡龙辅助色，色序固定避免图例错乱；趋势图用主粉（支出）与收入绿（收入）。
- **对比度**：正文文字对比度 ≥ 4.5:1；粉色按钮上的白字需验证对比度，不足时加深主粉至 `#F75C8A`。

### 6.8 字体与形状

- **字体**：圆润无衬线字体，数字采用等宽/圆体以对齐金额。
- **圆角**：卡片 16px、按钮 12px、输入框 12px。
- **图标**：线性圆角图标，颜色随分类变化。

## 8. 非功能需求

| 类别 | 需求 |
| --- | --- |
| 性能 | 记账保存响应 < 1s；列表滚动流畅（虚拟列表）；冷启动 < 2s |
| 可用性 | 核心记账路径 ≤3 步；支持单手操作；字体/对比度满足无障碍 |
| 安全 | 数据本地加密存储；导出文件不泄露敏感信息 |
| 兼容性 | 移动端 iOS/Android；若为小程序/Web 需适配主流机型 |
| 数据一致性 | 金额精度统一两位小数，避免浮点误差（用分存储整数） |
| 可扩展性 | 数据模型预留多币种、多人账本扩展点 |

## 11. 风险与假设

| 风险/假设 | 影响 | 应对 |
| --- | --- | --- |
| 假设：用户愿意手动记账而非依赖自动同步 | 影响留存 | MVP 用「极速记账」降低门槛，后续引入账单同步 |
| 风险：记账是低频刚需，留存低 | 留存指标不达标 | 用预算预警、月度报告等钩子提升回访 |
| 风险：数据安全担忧 | 信任下降 | 本地加密 + 明确隐私说明 |
| 假设：单机使用，暂无云同步 | 换机丢数据 | 提供导出/备份，M4 上云 |
